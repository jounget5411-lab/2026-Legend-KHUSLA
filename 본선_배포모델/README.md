# 최종 V7 배포 모델 보관

V7 코드의 `본선/src/track_drive_cnn_gpt/config/perception_cnn.yaml`에 대응하는 로컬 배포 모델을 보관한다.
모델별 검증 근거와 SHA-256은 `manifest.json`과 `SHA256SUMS.txt`에 기록했다.

이 디렉터리는 학습 데이터셋이 아니라 추론에 사용하는 모델 파일이다.
설정의 원래 차량 경로는 `/home/xytron/xycar_ws/models/`이며, 차량에 배치할 때 모델 이름과 폴더 구조를 유지한다.
YAML 설정은 원본 V7 그대로 보존했으므로 개발 PC에서 실행하려면 환경에 맞는 별도 설정이 필요하다.

실제 차량 환경에서는 이 파일들 외에도 ROS1 모터 브리지, 조향 보정, 센서 및 라이브러리 설치가 필요하다.
전체 설명은 저장소 루트의 `본선_최종_V7_안내.md`를 참고한다.
